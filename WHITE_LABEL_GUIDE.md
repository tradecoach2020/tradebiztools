### 🚀 How to Deploy for Clients

#### **Step 1: Configure Client Branding**
1. Open the white-label demo panel (bottom-left of the app)
2. Create new client configuration in `client/src/config/branding.ts`
3. Add their:
   - Company name and logo
   - Brand colors
   - Contact information
   - Custom domain
   - Feature preferences

#### **Step 2: Environment Setup**
```bash
# Set client branding environment variable
VITE_CLIENT_BRANDING=premium-plumbing

# Deploy to their custom domain
# premium-plumbing.yourdomain.com
```

#### **Step 3: Custom Features**
- Toggle YouTube integration on/off
- Show/hide Facebook community
- Enable/disable AI design tools
- Customize trade-specific templates
